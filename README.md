# V.S Silver House Website

A beautiful, modern website for V.S Silver House - a premium silver jewelry and ornaments business.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, elegant design with smooth animations and transitions
- **Hero Section**: Eye-catching landing section with gradient background
- **About Section**: Company information with a two-column layout
- **Collections Showcase**: Six beautifully designed collection cards featuring different product categories
- **Features Section**: Highlights of what makes V.S Silver House unique
- **Contact Section**: Easy-to-find contact information with multiple channels
- **Smooth Navigation**: Fixed navbar with smooth scrolling to sections
- **Scroll Animations**: Elements fade in as you scroll down the page

## Sections

1. **Hero/Home**: Welcome section with call-to-action
2. **About**: Information about V.S Silver House and their heritage
3. **Collections**: Six product categories:
   - Rings & Bands
   - Necklaces & Chains
   - Earrings
   - Bracelets & Bangles
   - Decorative Items
   - Gift Articles
4. **Features**: Four key differentiators:
   - Pure Silver
   - Expert Craftsmanship
   - Quality Assured
   - Unique Designs
5. **Contact**: Location, phone, and email information
6. **Footer**: Copyright and social media links

## Technologies Used

- HTML5
- CSS3 (with modern features like Grid, Flexbox, and CSS animations)
- Vanilla JavaScript for interactions
- Google Fonts (Playfair Display & Poppins)

## Customization

To customize the website for your needs:

1. **Contact Information**: Update the contact details in the Contact section
2. **Colors**: The main color scheme uses purple/blue gradients (#667eea, #764ba2) and silver (#c0c0c0)
3. **Images**: Replace emoji placeholders with actual product images
4. **Social Media**: Update social media links in the footer
5. **Content**: Modify text content to match your business details

## How to Use

Simply open `index.html` in any modern web browser. No build process or dependencies required!

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
