# Elegant Jewels - E-Commerce Website

A clean, mobile-responsive e-commerce website for silver, gold-plated, and moissanite jewelry business.

## Features

- **Homepage**: Elegant hero section with featured products, new arrivals, and shop by category sections
- **Product Listing**: Easy-to-manage product listing system with categories and filters
- **Product Details**: Stylish product pages with image gallery, descriptions, and pricing
- **Shopping Cart**: Full cart functionality with add, remove, and quantity updates
- **Checkout**: Complete checkout process with form validation
- **Navigation**: Responsive navigation with search functionality and mobile menu
- **Contact & About**: Contact page and About Us section
- **Social Media**: Instagram and Facebook links integrated

## Design Features

- Elegant and modern design with neutral/pastel tones
- Beautiful typography using Georgia serif font
- Jewelry-themed icons throughout
- Smooth UX optimized for mobile devices
- Responsive layout that works on all screen sizes

## File Structure

- `index.html` - Homepage
- `products.html` - Product listing page with filters
- `product-detail.html` - Individual product detail page
- `cart.html` - Shopping cart page
- `checkout.html` - Checkout page
- `about.html` - About Us page
- `contact.html` - Contact page
- `styles.css` - Main stylesheet
- `script.js` - JavaScript functionality
- `data.js` - Product data and categories

## Usage

1. Open `index.html` in a web browser
2. Browse products by category or use the search function
3. Click on any product to view details
4. Add products to cart
5. Proceed to checkout

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Font Awesome icons
- LocalStorage for cart persistence

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## Notes

- Cart data is stored in browser localStorage
- Product images use placeholder icons (can be replaced with actual images)
- Form submissions show alerts (can be connected to backend)
- Social media links are placeholders (update with actual URLs)
