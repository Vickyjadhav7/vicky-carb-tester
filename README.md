# Luxe Jewels - E-Commerce Website

A modern, elegant, and fully responsive e-commerce website for a jewelry business specializing in silver, gold-plated, and moissanite jewelry.

## Features

### Homepage
- Elegant hero section with call-to-action
- Featured products showcase
- New arrivals section
- Shop by category cards
- Newsletter subscription
- Social media integration

### Product Categories
- **Silver Jewellery**: Kids Kade, Ladies Kade & Chudiyan, Mens Kade, Baliyan (Hoops), Payal (Anklets), Mens Bracelet, Mens Chains, Mens Rings, Ladies Rings, Ladies Bracelets
- **Designer Inspired**: Van Cleef Set, Gold Plated Cartier Bracelet
- **Gold-Plated Jewellery**: Ladies Sets, Ladies Bracelet
- **Moissanite Jewellery**: Cuban Chain, Cuban Bracelet

### Product Features
- High-quality product images
- Detailed product descriptions
- Price display with sale badges
- Customer ratings and reviews
- Product filtering and sorting
- Image gallery with thumbnails
- Add to cart functionality
- Quantity selector

### Shopping Experience
- Full shopping cart functionality
- Add/remove items from cart
- Quantity adjustment
- Real-time price calculations
- Free shipping on orders over $100
- Checkout form with validation
- Order summary

### Additional Pages
- **About Us**: Company story, values, and guarantees
- **Contact**: Contact form, business information, FAQ section

### Design Features
- Modern, elegant design with neutral color palette
- Luxury serif typography (Cormorant Garamond) for headings
- Clean sans-serif font (Montserrat) for body text
- Smooth animations and transitions
- Responsive navigation with mobile menu
- Sticky header
- Search functionality
- Cart count indicator

### Mobile Responsiveness
- Fully responsive design
- Mobile-optimized navigation
- Touch-friendly interactions
- Responsive product grids
- Mobile-friendly forms

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JS for all functionality
- **Font Awesome**: Icons
- **Google Fonts**: Typography

## Getting Started

1. Open `index.html` in a web browser to view the homepage
2. Navigate through different pages using the navigation menu
3. Browse products by category or view all products
4. Add items to cart and proceed to checkout
5. Explore the About Us and Contact pages

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #D4AF97;
    --secondary-color: #8B7355;
    --accent-color: #E8D5C4;
    /* ... more variables */
}
```

### Products
Modify the products array in `script.js` to add, remove, or update products.

### Content
Update HTML files to change text, links, and structure.
