# Elegant Jewels - E-commerce Website

A clean, mobile-responsive e-commerce website for silver, gold-plated, and moissanite jewelry business.

## Features

- **Homepage** with featured products, new arrivals, and shop by category sections
- **Product Listing** with category filters and search functionality
- **Product Detail Pages** with image gallery, descriptions, and pricing
- **Shopping Cart** with localStorage persistence
- **Checkout Page** with form validation
- **About Us** and **Contact** pages
- **Responsive Design** optimized for mobile, tablet, and desktop
- **Social Media Integration** (Instagram, Facebook links)

## Getting Started

1. Open `index.html` in a web browser
2. No build process required - pure HTML, CSS, and JavaScript

## File Structure

```

├── index.html          # Homepage
```

## Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript
- Font Awesome Icons
- LocalStorage for cart persistence

## Design Features

- Elegant neutral and pastel color scheme
- Modern typography with serif and sans-serif fonts
- Smooth transitions and animations
- Mobile-first responsive design
- Jewelry-themed icons and imagery

## Browser Support

Works on all modern browsers (Chrome, Firefox, Safari, Edge).

## Notes

- Product images are currently represented by emoji icons. Replace with actual product images in production.
- Cart data is stored in browser localStorage.
- Form submissions are currently handled client-side. Integrate with a backend for production use.
